# irtea <img src="man/figures/logo.png" align="right" height="139" alt="irtea-Logo" />

Datensätze, Folien und Übungsheft zur Übung B.F.3 Diagnostik und Testtheorie
an der RPTU Kaiserslautern-Landau.

- Website mit Folien und Übungsheft: <https://sbissantz.github.io/irtea/>

## Installation

```r
install.packages("pak")
pak::pak("sbissantz/irtea")
```

## Datensätze

```r
data(personality_items, package = "irtea")
```
